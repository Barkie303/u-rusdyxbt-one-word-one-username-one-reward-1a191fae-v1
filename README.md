## The entry

One word, one username, one reward. The program writes the entrant's own
make.fun username — `barkie303` — to `/output/entry.txt`, and nothing else.

The gate requires 1–30 characters of UTF-8 text; `barkie303` is 9
characters, a single word with no spaces and no gloss. The judge's first
criterion is that the entry is a real make.fun username, the entrant's own
handle — and this is exactly that.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node --experimental-strip-types main.ts
```
